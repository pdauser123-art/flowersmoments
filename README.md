# 花驛 Sophia Florist (`flowersmoments`)｜官方課程與商業合作網站

本儲存庫（Repository 名稱：**`flowersmoments`**，與花驛官方 Instagram [@flowersmoments](https://www.instagram.com/flowersmoments?igsh=aW81djhvcmN3bTk5) 同名）為 **花驛 Sophia Florist（主理花藝師：鄭家俞）** 之官方教學與業務推廣網站。

採用**全自動裝置偵測響應式架構（Auto-Responsive Mobile, Tablet & Desktop）**，當學員或客戶用手機（包含 LINE、Instagram、Facebook 內建瀏覽器、Safari、Chrome）、平板或電腦點開網址時，系統會 **100% 自動適應螢幕並切換最佳版面**，完全不需手動按任何切換按鈕。

## 一、 網站內容與功能特色

1. **首頁主視覺與三地教室常態開課**：

   * 品牌理念：在山海與日常之間，留一段與花相伴的時光（涵蓋六大教學系列、多元體驗形式、全齡花藝學習）。

   * 上課據點：**台東教室（Fun Trip - 福美海景渡假民宿）**、**高雄教室**、**屏東教室**隔週常態開課中。

2. **四大教學體系與六大課程系列（全面採直接諮詢制）**：

   * **歐式古典花型系列**（台東／高雄／屏東教室・定期常態班／證照班）

   * **自然結構與現代花藝創作**（台東／高雄／屏東教室・定期常態班／證照班）

   * **手綁花束與 Ajour 新娘捧花**（台東／高雄／屏東教室・花束與婚禮專題）

   * **山與海的綠境花藝・戶外教學**（戶外地景工作坊，依當期活動公告）

   * **歲末聖誕與祈福花藝**（台東／高雄／屏東教室・節慶與跨界文化）

   * **小小花藝師兒童課**（台東／高雄／屏東教室・兒童美學與校園社團外派）

3. **校園社團、企業包班與客製花禮合作提案**：

   * **SERVICE 01｜校園與機構教學**：校園社團、寒暑假營隊、樂齡花藝。

   * **SERVICE 02｜企業與團體包班**：企業舒壓工作坊、品牌體驗、團體包班。

   * **SERVICE 03｜花禮與空間訂製**：婚禮花藝、節慶花禮、商業空間佈置。

4. **隱私保護與彈性 Google 報名表單機制**：

   * **不公開顯示銀行帳號**：統一改為「確認報名後由 LINE 私訊提供匯款帳號」。

   * **內建快速諮詢訊息產生器**：支援「預約／諮詢個人課程」與「洽詢學校／企業業務」雙模式切換，填寫後可一鍵複製諮詢文字並開啟官方 LINE 或 FB 粉專傳送。

   * **隨時更換最新 Google 報名表單網址（頁首置頂＆預約區同步顯示）**：內建「站長更換最新 Google 表單網址工具」（位於網頁底部），貼上最新一期表單連結後，系統會自動在「頁首置頂公告橫幅」、「預約洽詢區頂部橫幅」與「右下角浮動報名按鈕」同步顯示，方便插花學員一進入網頁即可立即點開報名，並可一鍵匯出更新後的 `index.html`。

## 二、 操作與技術需求

* **適合手機、平板與桌面瀏覽**：

  * 採用響應式網頁設計（RWD Media Queries）結合裝置自動辨識機制，完美支援手機、平板與桌面電腦瀏覽。

  * **手機與平板瀏覽**：自動轉換為單欄好讀版面，並浮現**頂部橫向滑動快速導覽列**；表單輸入框採用 `16px` 字級防止 iOS 點擊時畫面自動縮放，按鈕具備 `44px` 以上觸控友善高度。

  * **桌面電腦瀏覽**：自動呈現多欄寬螢幕版面與置頂玻璃擬態導覽列（若在電腦上將瀏覽器視窗拉窄，亦可即時預覽手機與平板排版）。

* **免建置單頁靜態架構**：

  * 以標準 HTML5、CSS3 與原生 JavaScript 建置，內嵌高解析向量 LOGO 與花藝實拍作品圖檔，無須額外後端伺服器或套件編譯，可直接部署於 GitHub Pages。
