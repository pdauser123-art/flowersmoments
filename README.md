# 花驛 Sophia Florist (`flowersmoments`)｜官方課程與商業合作網站

本儲存庫（Repository 名稱：**`flowersmoments`**，與花驛官方 Instagram [`@flowersmoments`](https://www.instagram.com/flowersmoments?igsh=aW81djhvcmN3bTk5) 同名）為 **花驛 Sophia Florist（主理花藝師：鄭家俞）** 之官方教學與業務推廣網站。

採用**全自動裝置偵測響應式架構（Auto-Responsive Mobile & Desktop）**，當學員或客戶用手機（包含 LINE、Instagram、Facebook 內建瀏覽器、Safari、Chrome）點開網址時，系統會**100% 自動切換為手機版畫面**，完全不需手動按任何切換按鈕！

## 一、 網站內容與功能特色

1. **首頁主打與三地教室常態開課**：
   - 首頁主打：**定期常態班 ＆ 定期證照班**。
   - 上課據點：**台東教室（Fun Trip - 福美海景渡假民宿）**、**高雄教室**、**屏東教室**隔週常態開課中。
2. **六大課程體系（全面採直接諮詢制，不公開現成報價）**：
   - **歐式古典花型系列**（台東／高雄／屏東教室）
   - **自然結構與現代花藝創作**（台東／高雄／屏東教室）
   - **手綁花束與 Ajour 新娘捧花**（台東／高雄／屏東教室）
   - **山與海的綠境花藝・戶外教學**（戶外地景不固定，依當期活動公告）
   - **歲末聖誕與祈福花藝**（台東／高雄／屏東教室）
   - **小小花藝師兒童課**（台東／高雄／屏東教室・校園社團外派）
3. **隱私保護與彈性 Google 報名表單機制**：
   - **不公開顯示銀行帳號**：統一改為「確認報名後由 LINE 私訊提供匯款帳號」。
   - **隨時更換最新 Google 報名表單網址**：已移除舊表單按鈕，並內建**「⚙️ 站長更換最新 Google 表單網址工具」**（位於網頁最底部），可隨時貼上最新一期表單連結並一鍵匯出更新後的 `index.html`。
4. **全自動手機版／電腦版切換體驗**：
   - **手機或平板開啟時**：系統自動識別行動裝置與螢幕寬度，自動呈現**頂部橫向快速滑動選單**、**單欄大字體課程卡**與**底部固定懸浮行動列**（「💬 LINE 諮詢」、「📸 瀏覽 IG 作品集」、「✍️ 預約／洽詢」）。
   - **電腦開啟時**：自動呈現多欄寬螢幕電腦版排版（若想在電腦上測試手機畫面，只要將電腦瀏覽器視窗拉窄即可自動變換為手機版）。
